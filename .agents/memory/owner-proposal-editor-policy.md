---
name: Owner proposal editing policy
description: Why the Santa Beatriz client proposal uses Replit-managed saved configuration rather than another admin login.
---

For the Santa Beatriz investment proposal, the user selected “Manage saved edits
through Replit.” Visitor financial and inventory adjustments are temporary;
authorized collaborators manage saved defaults and assets through Replit.

**Why:** No existing proposal-admin authentication system was found, and the user
explicitly chose Replit-managed configuration instead of introducing another
admin system or login.

**How to apply:** Do not add a public Save/upload endpoint, persistence for
visitor edits, a new login, or a database for this proposal unless separately
requested. Treat supplied budgets as evidence, not mathematical authority:
retain supplied ranges as references while calculating from their actual item
amounts and flagging discrepancies rather than inventing balancing expenses.
