## Sources consulted

| Source | Facts used and cautions |
| --- | --- |
| [Airbnb service fees](https://www.airbnb.com/help/article/1857) | Fee models, applicability and migration differ. Do not present one host percentage as universal. Use actual account/reservation statements. |
| [Airbnb calendar synchronization](https://www.airbnb.com/help/article/99) | Imported calendars refresh automatically every three hours; manual updates have limits. Calendar blocking behavior varies by the other site. iCal is not an instantaneous, conflict-free guarantee. |
| [Booking.com commission](https://partner.booking.com/en-gb/help/payments-payouts-invoices/invoices/understanding-your-commission) | Commission depends on agreement, country/property and relevant charges. Check the account statement; do not invent a universal rate. |
| [Hostaway vacation-rental guide](https://www.hostaway.com/vacation-rental-guide) | Operational topics include readiness, cleaning, maintenance, reporting, communication and connected systems. Vendor claims are not independent proof of an IPM outcome. |
| [Vrbo damage-deposit policy](https://www.vrbo.com/tlp/trust-and-safety/damage-deposit-policy) | Disclosure, supported options and permitted uses matter. Deposit guidance remains a specialist-review draft. |
| [IRS Topic 414](https://www.irs.gov/taxtopics/tc414) | U.S.-specific rental income, expenses and recordkeeping. Never extrapolate to owners in other countries. Used only in the private deposits draft. |

Research was used for original writing, not copied articles. Numerical examples are explicitly illustrative. No article claims an actual IPM property result, invented testimonial or first-person incident.
